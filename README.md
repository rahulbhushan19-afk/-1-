# संधि महारथी — KBC Style Quiz (Advanced+)

GitHub Pages के लिए single-file Hindi Sandhi quiz.

## इस संस्करण में क्या बदला है
- 30 **उच्च-उन्नत स्तर** के प्रश्न।
- प्रश्न केवल सीधे शब्द-रूप पर नहीं, बल्कि **संधि-विच्छेद, नियम, संधि-प्रकार और गलत वर्गीकरण पहचानने** पर भी आधारित हैं।
- हर उत्तर के साथ पहले से अधिक **व्याख्यात्मक explanation**।
- Correct answer positions को source bank में **A=8, B=8, C=7, D=7** के रूप में संतुलित किया गया है।
- इसके अतिरिक्त, quiz चलने पर हर प्रश्न के चारों विकल्प **हर बार random shuffle** होते हैं और answer key अपने-आप synchronize रहती है।
- 50:50 lifeline, संकेत, instant feedback, score और mobile responsive KBC-style UI बरकरार हैं।

## GitHub Pages पर चलाने का तरीका
1. GitHub में नया repository बनाएं।
2. `index.html` upload करें।
3. Settings → Pages → Deploy from branch → `main` / root चुनें।
4. GitHub Pages URL खोलें।

## Scoring
- सही उत्तर: +10
- गलत उत्तर: -3
- 50:50: एक बार उपयोग
